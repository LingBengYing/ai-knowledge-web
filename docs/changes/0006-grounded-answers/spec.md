# Spec

1. 新增具有独立导航 URL `#/answers` 的知识问答视图。仅 Java 配置同时声明 `answers`、`sources` 才启用；否则说明未启用，不伪造回答。
2. 用户可问全部当前可访问的已发布资料，也可从列表单行或选中完整集合进入问答。全库请求省略 `document_ids`；所选范围逐个原样发送，不过滤未发布项、不在空范围或错误时回退全库。范围固定并明确显示，切换范围清除旧答案。
3. 问题不能为空，最多4096 UTF-8字节。POST `/v1/answers` 只发送一次；按钮防重复，显示处理状态、取消等待入口。取消仅停止本地等待，不宣称取消服务器任务。身份切换、范围切换、重新提问使旧请求结果失效。
4. HTTP200的 `answered` 与 `abstained` 分别显示答案和拒答原因。答案、文档名、quote均用纯文本显示；模型文本不渲染HTML或自由生成链接。结果显示服务器answer_id，引用编号、文件名、页码、摘录及版本。
5. 点击引用，以当前身份GET精确服务器来源 URL `/v1/sources/{answer_id}/{1..32}`；回读必须属于当前答案/编号并匹配引用身份。来源失效、404或401不能继续显示旧摘录为当前验证成功；401复用现有身份清除。来源仅展示返回内容，不从偏移自造引用或页码。
6. 开发代理只扩展精确POST answers及GET sources路由，无query、编码ID、额外动作、自由链接或自动重试。普通请求及上传原期限保留，问答独立有界180秒期限；原JSON/响应限额、Host/Origin/Auth/Cookie边界保留。仅localhost开发使用。
7. 保留所有现有回归；增加请求范围、拒答、来源校验、旧响应失效、单次请求及代理合同验证；在真实浏览器走通问答与来源。若使用loopback模型/向量服务，明确只证明功能闭环，不认证真实provider语义质量或生产。
