# Spec：仅召回时的范围选择

状态：LOCAL_VERIFIED。实际四项 DOM RED→GREEN、435 全量及语法通过，原 431 身份与断言完整保留；页面和部署未验。

1. 已连接且任一问答模式或 retrieval_test 可用时，资料行、批量和详情范围入口可见；仅召回时分别显示“测试召回”“在选中资料中测试召回”“在本资料中测试召回”。无这两类能力或身份不可用时保持原门禁，未发布项和 can_answer=false 不作为范围选择资格。
2. 当前文字模式在 retrieval_test 可用时保持文字模式；当前模式不能使用时，选第一个实际可用模式，文字召回也属于可用模式。正式问答提交及继续问答仍要求原 answers/sources 配对，来源能力和附件规则不变。
3. 单选和多选复制原完整 document_ids 及顺序，不过滤未发布项。任一项不可用时显示服务器错误，不删项重试。显式 [] 保持空范围；null 仅由用户明确打开全部范围产生，请求省略 document_ids。
4. 指定范围下“测试全库召回”在仅召回时可用；点击才清空所选范围。范围、问题、身份改变使旧预览和迟到结果失效。入口导航不自动请求；取消详情脏草稿离开不改变问题、范围、草稿或现有结果。
5. 仅文字召回时，能力概述及模式提示明确可以召回、不生成回答；使用既有“测试当前问题与范围”按钮。保持完整问题、参数、片段校验、同版本原件及 RRF 分数语义。

不改后端、模型配置、索引、代理或来源协议，不增加依赖。保留全部原 431 项用例；新增真实 DOM 用例先在旧产品实现实际失败，再做最小产品修复和完整 check/test。浏览器、真实 provider 与部署仍 NOT_RUN。
