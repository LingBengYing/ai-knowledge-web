# 操作合同

`document_replacements` 能力开放时，详情独立读取新版本状态。编辑者在服务器 can_upload 许可下选择相同资料类型的文件并明确上传；显示新文件名、解析进度及“建立新版本索引”。can_index 许可时明确构建，不自动调用模型。

独立 Session 跟随当前身份、资料和候选版本。候选任务不占用旧资料行的任务槽，读取当前原件优先实际 active_revision_id；候选处理期间仍可打开旧原件和来源。不清空目录/标签草稿、问题或完整范围。published 响应只触发授权列表回读，确认新 publication 后沿原逻辑使旧来源失效。

三个精确 API 与后端0038一致。raw 上传30秒、20MiB（图片10MiB），GET普通10秒，index JSON180秒及独立2在途；其余代理、鉴权和限额保持。写请求不自动重发，未知结果先刷新。嵌套任务严格使用既有安全 shape，页面由用户验收。
