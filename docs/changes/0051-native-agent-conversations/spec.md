# 合同

- 原生Agent配置engine为knowledge-native-agent；不兼容混用旧内部DB-GPT协议。
- GET/POST /v1/knowledge-conversations；GET/PATCH/DELETE /{id}。
- #/ask/{id}固定对话地址；首问题先创建一次对话，再带conversation_id发起一次任务。
- 新建对话不删除历史；改名原地保存；删除必须确认，处理中须先停止任务。
- 完整原始轮次从服务端恢复，任务恢复只GET，不重发问题；重启中断显示安全原因。
- 压缩由后端生成并持久化，前端只显示状态/覆盖轮次，不接收内部摘要、思考或工具正文。
- 分页加载列表，严格核对turn数量/编号/运行ID与活动状态；异常不使用假数据。
- 历史GET也分页，默认20轮/约2MiB；前端按服务端has_more顺序恢复全部原始轮次，并检查总数/连续ordinal，不受单个全历史JSON大小限制。
- 提交响应未知时阻止继续POST，提供“核对已提交的问题”读取会话；引用返回保留当前会话URL。
- 原有引用阅读、草稿保存、公开进度和禁隐式重试保持。沿用绿色界面，不增加冗余说明。
