# 0035 交付记录

## 实现
- 顶部只保留问答、资料库、设置；管理区二级导航为资料、处理任务、召回测试，支持独立 hash 地址。
- 资料页突出导入、搜索和列表，刷新/本地预览收进工具菜单；行操作以打开和更多呈现，保留原权限/能力门禁。批量选择可进入独立召回范围。
- 资料详情分为原文件、摘要、整理信息、处理与版本；移动已有 DOM 节点，切换分区不重建表单，不自动提交。离开媒体分区暂停播放。移除不可操作的迁移中删除占位按钮，保留真实受控清理入口。
- 处理任务采用列表/详情双栏，任务元数据折叠，仍明确只有当前资料页的任务。
- 召回测试拥有独立输入和完整范围，参数默认折叠；左侧输入，右侧原文结果。允许修改查询时停止旧等待；来源回读继续核对同版本/SHA，离页释放读取。带入问答复制完整问题与范围，不自动发送。没有新增后端不支持的历史记录或分段编辑。
