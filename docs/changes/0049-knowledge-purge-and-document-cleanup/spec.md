# 行为合同

1. 已删除知识页列表和详情同时提供恢复与“彻底删除”。active页不能从UI永久删除；入口不触发写入。
2. 操作前读取当前页状态与最新version/lifecycle_version，只有deleted才展示不可恢复确认。取消、离页、重复点击不会发删除请求；确认后仅一次DELETE `/v1/wiki/pages/{id}/purge?version=N&lifecycle_version=L`，无body。回应必须为相同page_id及state=purged。
3. 成功后从本地已删除/活动缓存移除并回已删除列表；失败保留当前卡片/详情与安全错误，不自动重试。服务端双CAS、组织边界与原文件保存保持。
4. 资料维护的列表行、当前页批量选择和详情提供“删除并清理”动作，只有document_cleanup真实能力启用时可操作。确认明确影响原文件和索引、不可从本应用恢复；仍使用原CleanupSession单次写入与未知状态保护。
5. 清理受理/逻辑撤下/等待/受阻/完成分开显示，以服务端resource状态为准，不能把撤下或逻辑向量删除称为物理擦除。清理记录显示实际阶段与失败原因，不伪造完成。
6. 精确代理只增purge DELETE与双CAS参数；GET/POST、路径扩展、多余参数、带body或跨源请求继续拒绝。问答、模型配置、来源阅读和已有0048过程UI不改。
