# 操作契约

只有实际能力包含`batch_text_reindex`及既有文字索引、重建能力，当前页多选操作栏才显示“重建选中文本索引”。每份资料继续使用原`canReindex`资格，包括服务器`can_reindex`、当前已发布解析版本、无活动索引任务、媒体向量能力及未知结果刷新限制。

确认框列出合格资料名称和当前解析材料含义；内部捕获当前发布编号，同时列出不合格资料及不提交原因，明确数量、嵌入模型和Milvus费用、旧发布保留规则。只提交确认时捕获的合格项；提交前核对当前身份、选择、资格、发布、解析及索引任务指纹，变化时要求重新刷新确认。全部不合格时不能提交。

复用`POST /v1/management/document-actions`，请求仅包含`action: "reindex"`、`document_ids`和逐项准确的`base_publication_ids`，不发送目录或标签。成功必须有相同资料ID及`receipt.status: "queued"`，只表示后台任务已创建，不表示索引完成。显示逐项结果，取消成功项勾选，失败、结果未知及未提交项保留选择。

创建回执后回读当前授权资料列表，保留整理草稿、问题和范围。从原资料行、详情或“查看当前页索引任务”进入各自任务，沿用已有任务读取、轮询及终态回读。新发布由授权列表确认后，仍按原机制提示重新召回或提问；创建本身不会清除旧来源。

通信失败时本次提交的全部资料都标为待刷新，提示关闭确认框后刷新资料和任务核对，不自动重试。没有新批次任务、批量取消接口或代理路由。
