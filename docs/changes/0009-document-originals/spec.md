# Spec

1. 服务能力 `document_originals` 启用后，详情读取 `GET /v1/documents/{id}/original`，metadata 包含 document/revision/filename/type/MIME/SHA/size 和精确 `/v1/documents/{id}/revisions/{revision}/content`。校验与当前详情资料及源身份一致，完整读取原素材 1..20MiB、SHA 相符后才创建 Blob URL；不能回退问答引用、其他文件或本地文件。
2. PDF 使用原生 PDF 预览与打开/下载入口；TXT/MD 纯文本显示；图片直接显示原图；音频/视频使用原生播放器与原文件下载，浏览器不支持编码时明确提示。原文件读取不要求 parsed/indexed，合成无原文件记录保持明确不可用。
3. 关闭详情、离开资料视图、改变身份/上下文、打开另一资料时取消请求、停止播放器并撤销 URL，迟到结果不得恢复原文件。后台解析/索引刷新不覆盖整理草稿；metadata 编辑不能改变原文件身份。
4. 开发与认证外部代理仅增加上述两个精确 GET 路由，原文件独立20MiB限制、普通10秒期限；JSON、其他内容、Host/Origin/Cookie和身份边界保持。新增 Module 可作为同源静态资源加载，CSP仅使用已有 Blob对象/媒体权限。
5. 必跑语法和完整已有前端回归，新增真实 app 详情原文件显示/生命周期回归；当前 Java/SQLite 四类合成原文件通过前端 API/Module/精确代理贯通。不调用真实模型，不将本机验证写成公网页面复验。
6. 从资料详情进入问答/设置时关闭并清除旧详情状态；返回资料库不弹出旧文件，点击另一文件后详情与提问完整范围均绑定新文件。未保存草稿的取消离开不改变页面或提问范围；保留任务页面既有草稿工作流与后台刷新保护。
