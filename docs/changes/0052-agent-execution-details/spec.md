# 前端合同

- Event新增可选details，具体snake字段/nullable见后端0071/spec；旧事件保持名称，不编造细节。
- 展示实际检索词、工具名、源文档及位置、命中/阅读数量、耗时与安全失败码；规划选择的工具不冒称已执行。
- 仅返回reasoning_content才出现“模型思考”独立折叠区，纯文本转义，并标明模型输出未核验；无字段不伪造、截取明确提示。
- 每轮/每事件/每类details使用稳定键保存展开状态和焦点；轮询不会把工具详情和思考区相互串联。
- 同sequence的详情可由running更新到completed/failed/cancelled，计数不翻倍。未确定状态不得伪称成功。
- 对话刷新恢复公开详情；折叠区不是答案证据，不自动保存为知识、不加载外部链接、不暴露系统提示/密钥/完整工具正文。
- 沿用绿色界面和当前轮询，不新增动画库或图像素材。不改生产/旧运行实例，不推送。
