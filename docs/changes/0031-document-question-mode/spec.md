# 操作契约

单份范围从当前授权列表行选择默认模式：普通文档为文字；普通解析音频为音频转录问答；独立声音资料为声音理解；普通解析视频为视频画面；独立原视频音画资料为原视频画面。独立流程使用服务器现有registered_revision_id及无latest_job的行身份，不按文件名猜测。

图片在当前OCR上传能力及文字能力可用时默认文字，否则优先实际可用的原图视觉模式；无视觉问答能力时显示文字模式。列表未提供每份图片的原解析模式，因此不声称已从文件内容识别OCR或视觉路径。

已有问题文本保持，资料范围仍为完整单份ID。只有导航成功后才修改模式和范围；取消离开未保存整理表单时不修改。模式所需能力缺失时保留对应模式的未启用提示，不偷偷转到不兼容的文字问答。

多份范围和全库沿用用户当前可用模式；不自动过滤混合类型、缩减范围或改为全库。范围变更继续使旧问答、来源、召回和语音准备结果失效。
