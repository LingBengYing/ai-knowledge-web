# 呈现合同

- 最终答案保持服务器文字顺序和语义，只识别显式空行、标题、无序/有序列表及 `**强调**`；任意 HTML、自由链接仍作为文本。
- 正文 `[n]` 仅当编号属于当前已校验答案引用时生成原有 `#/answer-source/{answer_id}/{n}` 链接；其他编号保持文本。
- 仅隐藏独立的 `[source-N]`、`【source-N】`、`(source-N)`、`（source-N）` 内部编号标记；紧邻中英文词字符、路径符或文件扩展名时保留，普通术语、文件名、代码和句中裸编号保持。不从内部编号推断来源。
- 完整来源默认折叠，摘要展示资料数和引用数，按 `document_id + revision_id` 分组，同名不同资料、同资料不同版本不混并；每处编号和定位都可打开。
- 已保存的答案和草稿原文不变；进行中的 SSE 预览继续显示纯文本，完成前不发布来源或保存入口。
- 保持原有来源回读、版本校验、刷新恢复、展开状态和焦点处理。
