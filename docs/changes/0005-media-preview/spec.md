# Spec

1. 独立模态预览工作区，可选择或拖放单个本地文件；明确本地处理、不上传、不关联库内记录。通过详情入口显示原文件缺失原因，不能称资料已成功预览。
2. 图片支持适应、缩放、旋转及实际分辨率；音视频使用原生播放、时间进度、音量和全屏控制并允许倍速。无自动播放。PDF用浏览器内置查看器及新窗口备用入口；TXT/Markdown按纯文本显示，HTML/SVG/Office等不冒充可预览格式。
3. 文件类型由扩展名、受限MIME及基本文件标识共同检查。体积最多100MiB，文本最多2MiB，拒绝空文件、损坏/不支持类型。实际解码失败有可见错误。不支持的编码/编解码器不能称已验证。
4. 本地Blob URL替换、关闭、身份重置时释放；媒体暂停并解绑资源；异步读取有代次保护，迟到内容不能覆盖新文件或关闭的查看器。文本使用textContent，不执行Markdown/HTML。
5. 只增加一个前端静态模块和blob媒体CSP允许项，所有原API/Origin/Host/认证限制保持。无猜测原文件路由或任意远程URL输入。
6. 自动化覆盖类型/限额/异步竞态/释放；浏览器使用明确合成的有效媒体文件验证。库内真实媒体仍受后端原文件API阻断，不能宣布其完成。
