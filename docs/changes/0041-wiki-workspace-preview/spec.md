# 行为规格

1. 默认打开知识总览：导航分为知识总览、知识页、原始资料、知识问答、知识关系、更新审阅和设置。
2. 知识页和原始资料拥有独立 hash URL；可从知识页来源、答案引用、关系视图进入并使用浏览器返回。
3. 知识页显示跨资料组织后的概览、章节、来源和相关页。来源与派生知识分开，不能把知识页摘要冒充原始证据。
4. 资料支持文件级关键词搜索、类型筛选；预览导入只读取文件名/大小，不读取或上传正文、不声称解析成功。
5. 知识问答采用固定合成案例，展示意图、查找过程、回答和逐文件来源。未知问题明确未接后端，不伪造回答；输入“灯塔”展示项目/设备两种含义，不把所有资料拼成答案。
6. 关系视图的节点和旁边的可访问列表都可打开知识页；更新审阅的采纳/暂不采纳仅修改本地预览状态。
7. 设置中的 Top K、检索方式、排序和阈值只保存到本浏览器预览配置，并明确不影响真实检索。真实模型和服务接入均待用户确认后处理。
8. 全程常显“前端确认版 / 合成示例 / 未连接后端”；保存问答只生成本地草稿，不写入生产 Wiki。提供清空本地预览的明确操作。
9. 桌面及窄屏可用，键盘可达；长内容不溢出，交互有焦点、空态与结果提示。

验收：本地 18090 独立静态服务器，无 API 转发；实际浏览器走通知识页、来源、搜索、问答、审阅和设置；相关新增测试及完整前端回归。RAG/provider acceptance 不适用，本轮没有接入生产数据或模型。
