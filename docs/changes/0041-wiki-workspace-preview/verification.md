- 独立入口而非覆盖现有业务界面：当前 Wiki 后端合同不存在，且用户明确先确认前端，因此不制造真实接口或影响原联调功能。

- 真实 PDF / 图片 / 音视频原件及精确播放定位未接入；来源页仅文字样稿，明确没有实际播放器。
- 没有联网回答、语义检索、Wiki 编译、真实差异生成、版本持久化或跨浏览器同步；本轮 RAG acceptance 不适用。
- 不改后端、不新增模型请求、不提交推送或部署；待前端确认后按 backend-handoff 中候选需求继续设计。
