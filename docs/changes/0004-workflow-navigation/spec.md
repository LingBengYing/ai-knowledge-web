# Spec

1. Hash导航提供资料库、处理任务、设置独立视图，支持刷新、前进后退与未知地址回退；页面标题、焦点、当前导航同步。
2. 资料库以列表为主；目录收纳在次级栏，筛选按需展开，批量操作仅在有选择时出现。选择、筛选、服务器分页及权限不放宽。
3. 详情使用模态侧抽屉，具备关闭、Escape、焦点约束；未保存编辑离开前确认。任务刷新保留未保存表单及权限更新行为。
4. 处理任务页面从当前已加载的授权资料页展示解析/索引任务，明确不是全库历史。点击查看任务、上传或索引创建成功进入任务页；原有独立轮询、终态、错误暂停、取消重试和费用确认保留。
5. 设置集中身份与真实服务能力说明。配置失败可以重新连接；凭证不持久化。未接通问答不提供虚假交互。
6. 保留全部已有测试，新增实际导航与交互验证。桌面和窄屏浏览器验收，记录真实服务与合成测试边界。RAG acceptance不适用，本次不修改回答与检索。
