# 行为合同

1. 原始资料页仅展示资料列表和每份资料的真实处理/可问状态，不再展示本次解析/索引卡片、任务编号或刷新任务按钮；已有处理任务菜单保持。
2. 普通导入仍只发送一次原文件上传请求，由服务端持久续接解析与索引。导入提示说明自动处理与任务菜单，不产生前端补建索引POST，不自动重试。
3. 资料状态合并现有management批量分页的latest_job/latest_index_job；解析成功不冒充已发布，失败不显示可问。只读刷新在终态停止，离页取消读取与计时器，迟到结果不能回写其他页面。
4. 来源详情移除“建立索引”按钮。历史补建、重建与失败重试保留在既有资料维护/任务菜单，不要求普通新资料再点击索引。
5. 视觉风格、精确来源身份、文件字节上传、重复提交保护和现有问答/模型/知识页行为保持。真实模型和生产验收由root单独执行，本切合成UI测试不冒称生产完成。
6. 服务端`auto_index`的pending/dispatching/failed状态在处理任务菜单恢复；准备阶段只读刷新management分页，submitted交由真实索引任务表示、不重复造任务。失败原因映射固定安全文案，未知错误不原样展示，无自动重试或伪造任务编号。
