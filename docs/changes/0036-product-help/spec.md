# Spec

- 准备流程补充：后端能力未就绪时问题仍可编辑；常显“配置模型”“导入 / 管理资料”。返回帮助页只读刷新能力，保留问题与完整所选范围；不自动应用配置或提交查询。按当前身份、入口epoch及在途请求保护刷新结果；身份改变清空旧上下文。不以当前页资料数推断整库是否为空。

- 独立`#/product-help`入口，支持从资料列表完整所选集合进入，也可选择全库。产品型号版本先沿目录/标签整理，帮助页明确当前范围，不自动过滤掉未发布所选项，不将`[]`改成全库。
- 调用后端`POST /v1/product-help/search`，仅显式提交发送；question、document_ids、top_k（每类默认5、最多10）、rerank（默认true）。不自动重试或顺带调用问答、解析或索引。
- 分组展示说明文档与使用视频的真实命中：文件、原文片段、来源类型、页码/时间、阅读/播放动作。没有某一类时显示空态，不补造卡片或按文件名猜定位。
- 结果明确是“原文检索片段，非生成答案”；字幕、ASR与画面OCR分清来源，时间不得从文本长度推算。旧通用问答保留，可携问题/完整范围跳转但不自动发送。
- 原件读取沿既有服务端授权和完整版本/SHA核对，拒绝任意URL；页码与时间只用后端locator。修改问题/范围/参数、离页、身份变化后旧响应失效，释放Blob/媒体读取并暂停播放。保留加载、错误、空结果和未配置提示。
- 仅增加精确代理路由，不扩大URL/Origin/Host/身份信任。后端尚未开放capability时如实提示，不假造可用。
- 不改旧测试/证明/来源合同；当前停测指令优先，未运行真实检索和RAG acceptance必须写明。
