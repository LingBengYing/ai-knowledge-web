# Spec

1. 登录、退出、会话失效清理和秘密保护保留；登录后的组织成员可执行服务已支持且资料生命周期允许的维护及模型配置动作，不以reader或can_edit划分能力。
2. 问答、召回均展示固定“组织共享全库”，不再提供文档范围选择。行、详情、批量问答入口不发送document_ids；选中项仍可用于移动、标签、更新、索引和清理。
3. 原问题不截短，不设置HTML maxlength或4096 UTF-8字节业务限制。语音转录确认使用同一问题合同；非法Unicode和控制字符仍作为输入格式错误处理。
4. 召回返回的scope_count不再限制128；统一知识问答引用不再限制32条。保留TopK的返回数量含义，不把返回片段数当全库权限或资料数量上限。
5. 统一问答提示“检索资料并生成回答”，不宣称独立事实核验已通过。答案和摘录以纯文本展示，来源必须为服务器当前答案精确相对URL，版本、字符/时间定位、原件和SHA回读规则保持。
6. 保留实际传输、媒体解码和资源保护边界。本切没有删除专门音画入口原有事实证明、摘要条目数、附件数/字节数或媒体时长限制；不得把局部简化表述为所有功能无限制。

新合同替代历史“完整所选范围不扩库”及“reader不可维护”的相关测试期望；保留所有测试用例、来源反例、会话隔离及不自动重试断言。受影响用例的名称和断言随明确的新产品合同同步。
