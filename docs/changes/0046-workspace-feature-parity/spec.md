# 行为合同

1. 新版原生#/retrieval：复用既有RetrievalSession/服务器检索设置，问题输入、TopK和阈值等临时覆盖、命中片段/真实分数、同版本原件校验/打开，新版资料详情链接。文件查找不冒充向量召回。进入页面不触发模型；测试由用户显式提交。
2. 新版原生#/documents及#/documents/{id}：复用管理API/Session，过滤分页、显示名/目录/标签、批量移动/标签/重建/清理、单资料更新原文件/重建，保持同版本来源身份。删除/清理等沿用现有确认，不新增费用确认。
3. #/tasks从服务器资料latest_job/latest_index_job恢复任务，即使刷新也可查看；展示真实类型、进度/终态、失败原因，以及合同允许的取消/显式重试。不把最新任务列表称为全量历史。
4. 迁移旧版已提供的摘要/建议标签和专门媒体索引操作到原生维护详情，使用既有模块与配置能力，不能仅藏旧按钮。目录管理有明确入口。
5. 新导航包含召回/任务，原资料详情和空间设置不再出现/classic链接，详情维护保留document_id。旧/classic仍可独立访问兼容，不删除旧功能。
6. 模块使用小Interface：mount({container,document,window,api,config,route,navigate,notify,confirm})→{ready,destroy}，独立监听自身容器并清理请求/轮询/资源；主体路由由root统一接入，避免多worker改同文件。
7. 复用同源鉴权/精确代理/原件SHA/定位校验，未完成/空状态不假成功。错误显示固定安全说明、Agent任务编号与code，不暴露内部异常/正文/凭据。问答算法不改。
