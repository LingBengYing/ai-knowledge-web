# 行为合同

1. Agent 运行时默认展开真实阶段时间线，以最后服务端事件突出当前动作；仅接受现有固定事件类型，不显示任意模型文字或扩展字段。
2. planning 只表示分析查阅任务，不能断言最终写答案；searching/reading 只表示工具阶段已发起，不能冒称命中或成功读完。保留重复阶段，无假百分比、预填步骤或成功勾选。
3. 轮询自身的 reading phase 不是原文阅读。相同业务状态不反复重建 DOM；新事件更新保留历史回答的展开状态和当前焦点，不打断问题输入。
4. 完成后默认折叠查阅过程；可显示实际检索/阅读发起次数及最终已校验引用条数，区分证据不足结果。失败、取消、状态未知保留真实过程与原有安全诊断；取消成功仍以服务端响应为准。
5. 动效轻量且有限，遵循减少动态效果设置；当前状态可被读屏感知，展开、停止、刷新可键盘操作。任务编号与错误码保留在记录内。
6. 普通知识问答、引用阅读与保存草稿保持；不新增服务 API 或外部请求。本机合成协议/UI验证不认证新真实模型语义质量或生产发布。
