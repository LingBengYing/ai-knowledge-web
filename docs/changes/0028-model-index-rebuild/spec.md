# 页面操作

沿后端0039合同，`model_index_rebuild` 开放时，保存草稿后读取服务器资格。需要重建时显示资料数量与“重建索引并应用”，普通应用暂不可用。明确确认模型和向量服务费用后，POST `/v1/model-configuration/rebuild`，正文仅 `{version}`。GET同路径恢复资格和唯一批次，两请求均沿普通10秒及128KiB JSON边界。

结果严格读取7字段，批次严格读取9字段；queued/running/applying自动轮询，completed/failed停止。处理中暂停设置保存与普通应用，旧配置和已发布资料仍可查询。离页停止页面轮询，不取消后台任务；返回设置后重新读取。未知提交结果只允许刷新，不自动再次创建。

完成后先读取模型配置，确认active_version等于批次目标版本，再刷新运行能力和授权资料。清除旧召回/答案来源并提示重查，保留问题、完整范围和整理草稿。失败展示安全中文说明，可在服务器重新许可后明确创建新批次。没有取消接口，不显示取消后台任务按钮。
