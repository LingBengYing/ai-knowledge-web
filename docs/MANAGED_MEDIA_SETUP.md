# 网页配置文字模型后使用媒体资料

本轮对应后端0040、前端[0029记录](changes/0029-managed-media-setup/REVIEW.md)：已修复只有网页文字配置时，已配置媒体资源仍被旧文字环境前置条件挡住的问题。没有新增前端功能。2026-10-04 01:21:20 +08仅后端跳过全部测试编译运行包成功，未测试、部署或页面验收；下列为更新到本轮交付后的操作步骤。

## 先明确谁配置什么

用户在网页“设置”配置嵌入、重排、生成三个文字角色，保存草稿、按需手动测试，然后明确应用。无需为了启用媒体功能，再把这三个文字角色的模型名称和密钥复制到旧服务器环境。

服务管理员仍需提供既有独立媒体配置：原图Vision模型，音频/视频ASR模型，FFmpeg/FFprobe解码器，以及需要时的图片/音频向量模型和独立向量库。网页文字配置不会自动补全这些资源，也不会替代媒体模型密钥。资源构造与配置应用不调用模型；用户明确处理、索引和提问可能产生调用费用。

## 从配置到来源

1. 应用文字配置后，页面重新读取服务实际能力。点击“去导入资料”，选择已开放的资料类型与原文件。
2. 图片、音频转录或普通视频处理完成后，在资料行或详情明确建立索引。独立声音、原视频音画按各自详情提示显式建立。
3. 等索引发布后进入知识问答，选择对应证据模式，保留完整资料范围并填写问题。
4. 明确提问后点击引用，核对原图、页码或时间位置，打开保存的原文件。

看不到某个媒体入口时，请服务管理员核对该媒体资源和实际运行版本。不要重复保存文字密钥或重新上传来尝试开启未配置的能力。完整文字操作见[模型设置与召回](MODEL_SETUP_AND_RETRIEVAL.md)。本轮未运行测试、语法检查、浏览器或真实模型调用，当前不宣称页面或供应商已可用。
