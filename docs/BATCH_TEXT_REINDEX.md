# 在页面批量重建选中文本索引

当前状态：0041及前端0030已实现；2026-10-04 01:32:29 +08仅后端跳过全部测试编译运行包成功，未测试、部署或页面验收。正式范围见[正常操作契约](changes/0030-batch-text-reindex/spec.md)。

## 先确认用途

这项操作用当前已应用的文字模型，重建选中资料已经保存的完整解析材料。它不会重新解析原文件，不会应用未启用的模型草稿，也不会自动生成新的图片或音频向量。已有合格媒体向量由现有流程核对后复用；文字嵌入与索引写入可能产生服务商费用。

更换嵌入模型、修订或维度，需要在模型配置中使用全库“重建并应用”。这里的多选重建只处理明确确认的资料，各份资料独立完成。

## 从选择到查看进度

1. 完成文字模型配置并明确应用。服务还须实际开放批量文字重建能力；按钮不可用时，先核对已应用状态和资料资格。
2. 在资料列表的当前页勾选资料，点击“重建选中文本索引”。
3. 查看合格项，以及不具资格、不会提交的选中项和数量。确认框会列出实际处理的资料及已保存发布身份；没有写权限、有活动任务或版本已变化等资料不能直接提交。
4. 核对后明确确认。若确认前或提交前资料资格、发布、任务或登录身份发生变化，先刷新并重新确认，页面不会自动重新提交。
5. 阅读逐项回执。“后台任务已创建”表示已经排队；失败会单独显示原因。一项失败不会回滚其他已创建的任务。
6. 打开各资料行、详情或索引任务入口查看后台进度。批次创建响应不是索引完成通知。

失败及未提交项保留选择；问题、问答范围和整理草稿保持。后台处理时，旧发布继续可以查询。只有一份资料的新索引完整成功，这份资料才切换版本；失败或取消保留旧版本。切换后重新执行召回或问答，再打开新结果对应的来源。

## 不确定是否提交成功时

如果网络中断、超时或响应丢失，先刷新列表和任务，核对每份资料是否已经创建任务。不要直接重复点击提交；页面不会自动重试，也不会把结果未知当作全部失败。

对于明确失败的项目，先处理当前提示，再刷新资格和发布状态，重新选择并确认需要提交的资料。没有进入本次确认范围的项目不会在后台补交。
