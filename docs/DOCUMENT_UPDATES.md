# 更新原文件的页面操作

资料详情新增独立“更新原文件”区域，能力为 `document_replacements`。后端0038与前端0027需同步部署；当前实现状态见[记录](changes/0027-document-replacements/REVIEW.md)，本轮未运行自动化测试或浏览器验收。

1. 打开可编辑资料，点击“选择新原文件”，选择同类别的文档、图片、音频或视频并确认上传。
2. 等新版本解析完成，或独立声音/音画通道显示已保存，再明确点击“建立新版本索引”。
3. 查看该区域的独立进度。旧资料仍可使用，目录、标签、显示名称、权限与整理草稿保留。
4. 新版本发布后，页面回读授权资料列表。确认新版本后，重新测试召回或提问，再打开来源；原问题和完整范围保留。

模型或向量服务处理可能产生费用。更换原件不沿用旧图片/音频独立向量，新版本可在现有向量面板明确重建。提交结果未知时先刷新状态，不重复操作；任务失败时根据服务器提供的资格重新提交。
