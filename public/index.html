              文字模型

              填写三个模型 → 保存草稿 → 测试连接 → 应用配置。已有资料更换嵌入模型时，按下方提示明确“重建索引并应用”。应用后可导入资料、建立索引，再测试召回、提问和打开引用。

              嵌入和重排使用硅基流动；生成模型可选择硅基流动或 DeepSeek 官方。按所选服务商填写模型 ID 和对应密钥：硅基流动使用完整模型 ID，保留斜杠及大小写；DeepSeek 官方使用其控制台提供的模型 ID。

              嵌入用于检索，重排用于排序，生成用于回答。同一服务商的角色可使用同一账户密钥，首次配置时分别填写。更换服务商须重新填写对应密钥；只有服务商不变时，留空才会保留已保存密钥。保存后密钥输入会清空。

              保存草稿和普通应用不会自动调用模型。测试连接会发送合成输入；明确重建会用保存的解析材料调用嵌入模型与向量服务，都可能产生费用。向量库由服务管理员配置；未配置时仍可保存和测试模型。

              嵌入模型

              填写所选嵌入模型实际输出的向量维度，可在供应商模型说明中查看。已有资料改变模型或维度时，需明确重建索引并应用；服务器会为新配置准备独立索引。

              填写供应商提供的具体模型版本。若供应商未单独提供版本号，可使用固定模型 ID 作为版本标识；模型或版本改变时一并更新，不能填写 latest、default 或 unknown。
